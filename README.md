# # Exploratory Data Analysis (EDA) of E-Commerce Sales Data

## Project Overview

This project was completed as part of the DecodeLabs Data Analytics Program (Project 2). The objective was to perform Exploratory Data Analysis (EDA) on an e-commerce dataset and generate actionable business insights through data cleaning, statistical analysis, and pivot analysis.

The analysis focused on understanding sales performance, customer purchasing behavior, product performance, payment preferences, and marketing channel effectiveness.

---

## Objectives

* Clean and prepare raw data for analysis.
* Perform basic statistical analysis on key numerical variables.
* Conduct exploratory data analysis to uncover trends and patterns.
* Analyze product, customer, and marketing performance.

---

## Dataset Information

The dataset contains e-commerce transaction records, including:

* Order ID
* Date
* Customer ID
* Product
* Quantity
* Unit Price
* Total Price
* Items in Cart
* Coupon Code
* Payment Method
* Shipping Address
* Referral Source
* Order Status

## Data Cleaning Process

Data cleaning was performed using Excel Power Query.

### Cleaning Activities

#### Missing Values

* Identified 309 missing values in the **CouponCode** column.
* Replaced all missing values with **"No Coupon"** to maintain data consistency.

#### Missing Order ID

* Identified a missing value in the **OrderID** column.
* Based on the sequential pattern of the IDs, the missing value was replaced with **ORD200070**.

#### Data Type Formatting

Converted columns from **General** format to their appropriate data types, including:

* Date
* Text
* Whole Number
* Currency

This ensured accurate calculations and analysis throughout the project.

## Pivot Table Analysis

Pivot tables were created in Microsoft Excel to perform additional exploratory analysis.

### Analyses Conducted

#### Product Performance

* Revenue generated by product.
* Identification of top-selling products.

#### Payment Method Analysis

* Distribution of customer payment methods.

#### Referral Channel Performance (Order Volume)

* Number of orders generated by each referral source.

#### Referral Channel Performance (Revenue Contribution)

* Revenue generated by each referral source.

#### Shipping Address Analysis

* Distribution of orders across customer locations.

#### Coupon Usage Analysis

* Comparison of orders using coupons versus orders without coupons.
